# موقع بيض أبو نبهان

الموقع على GitHub Pages (مجاني). الطلبات والأسعار على Supabase (مجاني).

- الطلبات من صفحة order.html بتتسجل في قاعدة البيانات. التليفون والعنوان واللوكيشن بيقراهم صاحب المحل بس من لوحة التحكم.
- لوحة التحكم: dashboard.html. الدخول بلينك بيوصل على إيميل صاحب المحل.
- سعر النهارده: من لوحة التحكم اكتب البورصة والهامش واضغط "انشر السعر على الموقع".
- config.js فيه رابط المشروع والمفتاح العام (مصمم يكون علني، والصلاحيات بتتحكم فيها قواعد الأمان في قاعدة البيانات).
- ملاحظة: مشروع Supabase المجاني بيتوقف لو مفيش نشاط أسبوع. لو وقف، افتح لوحة Supabase واضغط Restore.
