# موقع بيض أبو نبهان

موقع ثابت (HTML) جاهز للنشر على GitHub Pages. مفيش سيرفر ولا قاعدة بيانات ولا مصاريف. كل الملفات في مستوى واحد (مفيش فولدرات)، والصور جوه الملف photos.js، فمحتاج ترفع الملفات دي بس.

## الملفات
- index.html: الصفحة الرئيسية
- order.html: صفحة الطلب (بتفتح رسالة واتساب جاهزة)
- dashboard.html: لوحة التحكم (سعر البورصة، رسالة الصبح، الطلبات، العملاء)
- prices.json: سعر النهارده اللي بيظهر في الرئيسية
- style.css و site.js و photos.js: التصميم والبرمجة والصور
- favicon.svg: أيقونة الموقع
- robots.txt

## خطوات الرفع على GitHub
1. ادخل على github.com وسجل دخول (أو اعمل حساب مجاني).
2. اضغط علامة + فوق ثم New repository.
3. الاسم مثلًا: abunabhan-eggs. اختار Public. اضغط Create repository.
4. في صفحة الريبو اضغط "uploading an existing file".
5. اختار كل الملفات اللي فوق مرة واحدة (index.html لازم يتحط في أول الريبو، مش جوه فولدر).
6. اضغط Commit changes.

## تشغيل الموقع (Pages)
1. من الريبو اضغط Settings ثم Pages.
2. في Source اختار "Deploy from a branch".
3. في Branch اختار main والفولدر / (root) ثم Save.
4. استنى دقيقة أو اتنين. الرابط هيظهر فوق في نفس الصفحة وشكله: https://اسم-حسابك.github.io/abunabhan-eggs/

## تسجيل الطلبات
الزبون بيملا صفحة الطلب (الاسم، التليفون، العنوان، وزرار مشاركة الموقع)، وبيتفتح عليه واتساب برسالة جاهزة ليك. انسخ الرسالة من واتساب، وافتح لوحة التحكم (الرابط + dashboard.html)، والصقها في خانة "ضيف طلب من رسالة واتساب"، والطلب يتسجل بالتليفون والعنوان ورابط الموقع.

## تغيير سعر النهارده
1. افتح لوحة التحكم، اكتب سعر البورصة والهامش.
2. اضغط "انسخ الكود".
3. في GitHub افتح الملف prices.json، اضغط أيقونة القلم (Edit)، امسح المحتوى والصق الكود، ثم Commit changes.
4. السعر بيظهر في الصفحة الرئيسية بعد دقيقة أو اتنين.

## مهم تعرفه
- لوحة التحكم بتحفظ الطلبات والعملاء في متصفح جهازك بس. لو مسحت بيانات المتصفح أو فتحتها من جهاز تاني هتلاقيها فاضية.
- بما إن الموقع عام، أي حد يعرف رابط dashboard.html يقدر يفتحها، بس هيشوف لوحة فاضية خاصة بجهازه، مش بياناتك. مفيش كلمة سر. الصفحة مش ظاهرة في قايمة الموقع، ومعمولها منع الظهور في جوجل.
- الريبو Public معناه إن أي حد يقدر يشوف الملفات، فمتحطش فيها أي حاجة سرية.
- عشان الموقع يظهر في جوجل: افتح search.google.com/search-console بحساب جوجل بتاعك وضيف رابط الموقع، وبعدين اطلب الفهرسة. ضيف كمان نشاطك في Google Business Profile (مجاني) بالعنوان عند الجامع الكبير.
